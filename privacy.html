プライバシーポリシー

最終更新日：2026年10月16日

1. 対象

このポリシーは、個人用の連携ツール「claude-mcp」（以下「本ツール」）に適用されます。本ツールの利用者は所有者本人のみです。

2. アクセスする情報

本ツールは、所有者本人が許可した範囲で、本人の Google アカウントの Google ドライブ、ドキュメント、スプレッドシート、スライド、カレンダー、Gmail のデータにアクセスします。

3. 情報の使い方

アクセスした情報は、所有者本人の指示に基づく作業（ファイルの読み書き、予定の確認、メールの確認など）のためだけに使います。広告、販売、第三者への提供には使いません。

4. 保存と共有

認証のための情報（トークン）は所有者本人のパソコン内にのみ保存されます。本ツールの開発者が運営するサーバーはなく、データを収集・保管しません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と転送は、制限付き使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

6. アクセスの取り消し

所有者本人は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセスを取り消せます。

Privacy Policy (English summary) — claude-mcp is a personal tool used only by its owner. It accesses the owner's own Google Drive, Docs, Sheets, Slides, Calendar and Gmail data only as authorized by the owner and only to carry out the owner's own instructions. Tokens are stored only on the owner's computer; no data is collected by, sold to, or shared with any third party. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the owner's Google Account settings.
